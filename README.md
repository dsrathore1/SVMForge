# SAGE

**An End-to-End Machine Learning and MLOps Project**

SAGE is a beginner-friendly, production-oriented machine learning project designed to demonstrate the complete machine learning lifecycle, including data preparation, model development, experiment tracking, deployment, cloud infrastructure, DevOps, and observability.

## Project Objective

Build an industrial predictive maintenance system using the AI4I Predictive Maintenance dataset from Kaggle.

The initial machine learning objective is to predict potential machine failures using industrial sensor measurements.
****
## Dataset

- **Source:** Kaggle
- **Dataset:** AI4I 2020 Predictive Maintenance Dataset
- **Problem Type:** Classification
- **Initial Algorithm:** Logistic Regression
- **Next Algorithm:** Decision Tree
